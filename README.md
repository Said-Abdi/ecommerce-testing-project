# E-Commerce Checkout System — Software Testing & Quality Engineering

A professional Python-based e-commerce checkout system designed to demonstrate software testing practices using Pytest, including functional testing, negative testing, boundary value analysis, defect detection, regression testing, and automated test reporting.

---

## Technical Features & Stack
- **Language:** Python 3.11+
- **Testing Framework:** Pytest with `pytest-cov`
- **Domain Capabilities:** Stock management, cart management, subtotal/discount/shipping calculation, decimal monetary precision.
